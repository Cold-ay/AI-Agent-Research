## Key Concepts

### Study Sequence

- **[[AI Agent Learning/04 - Advanced Knowledge/Knowledge Graph|Knowledge Graph]]**（知識圖譜）
  A representation of entities and typed relationships, often with attributes and provenance.
- **[[AI Agent Learning/04 - Advanced Knowledge/Graph RAG|Graph RAG]]**（圖譜式檢索增強生成）
  RAG that uses graph structure or graph-derived information to retrieve and organize evidence.
- **[[AI Agent Learning/04 - Advanced Knowledge/Multi-hop Reasoning|Multi-hop Reasoning]]**（多跳推理）
  Combining multiple evidence steps to answer a question whose answer is not in one isolated fact.
- **[[AI Agent Learning/04 - Advanced Knowledge/Agentic RAG|Agentic RAG]]**（代理式檢索增強生成）
  RAG in which an agent dynamically chooses retrieval steps, sources, or follow-up queries.
- **[[AI Agent Learning/04 - Advanced Knowledge/LLM Wiki|LLM Wiki]]**（LLM 維護的知識 Wiki）
  Here, a readable, persistent wiki whose concept pages and links are drafted or maintained with an LLM. The term does not denote one universal standard.
- **[[AI Agent Learning/04 - Advanced Knowledge/CAG|CAG]]**（快取增強生成）
  Cache-augmented generation, in the cited research sense, preloads a manageable knowledge corpus into model context and reuses cached computation.
- **[[AI Agent Learning/04 - Advanced Knowledge/Multimodal RAG|Multimodal RAG]]**（多模態檢索增強生成）
  RAG that retrieves evidence across modalities such as text, images, tables, audio, or video.
