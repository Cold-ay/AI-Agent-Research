## Key Concepts

### Study Sequence

- **[[AI Agent Learning/03 - Agent Core/Tool Calling and Function Calling|Tool Calling and Function Calling]]**（工具／函式調用）
  A model requests an operation using a named tool and structured arguments; application code decides whether and how to execute it.
- **[[AI Agent Learning/03 - Agent Core/Planning|Planning]]**（規劃）
  Choosing a sequence or structure of actions intended to reach a goal.
- **[[AI Agent Learning/03 - Agent Core/Task Decomposition|Task Decomposition]]**（任務分解）
  Breaking a goal into smaller tasks with clear inputs, outputs, and dependencies.
- **[[AI Agent Learning/03 - Agent Core/ReAct|ReAct]]**（推理與行動）
  An agent pattern that interleaves reasoning about next steps, actions, and observations.
- **[[AI Agent Learning/03 - Agent Core/Agent State|Agent State]]**（代理狀態）
  The explicit working data that describes a task’s current progress and execution status.
- **[[AI Agent Learning/03 - Agent Core/Memory|Memory]]**（記憶）
  Mechanisms for retaining and reusing information across steps or sessions.
- **[[AI Agent Learning/03 - Agent Core/Short-term Memory|Short-term Memory]]**（短期記憶）
  Task- or conversation-scoped information retained for the current interaction.
- **[[AI Agent Learning/03 - Agent Core/Long-term Memory|Long-term Memory]]**（長期記憶）
  Information stored for reuse beyond a single interaction or task.
- **[[AI Agent Learning/03 - Agent Core/Episodic Memory|Episodic Memory]]**（情節記憶）
  Memory of specific past events, actions, and outcomes.
- **[[AI Agent Learning/03 - Agent Core/Semantic Memory|Semantic Memory]]**（語義記憶）
  Stored facts, concepts, and relationships rather than a record of one particular event.
- **[[AI Agent Learning/03 - Agent Core/Reflection and Critic|Reflection and Critic]]**（反思／評審）
  A review step that checks a proposed answer or action against criteria and evidence.
