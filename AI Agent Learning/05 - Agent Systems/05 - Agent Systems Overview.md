## Key Concepts

### Study Sequence

- **[[AI Agent Learning/05 - Agent Systems/MCP|MCP]]**（模型上下文協議）
  Model Context Protocol standardizes communication between AI applications and servers exposing capabilities such as tools, resources, and prompts.
- **[[AI Agent Learning/05 - Agent Systems/Workflow vs Agent|Workflow vs Agent]]**（工作流與代理）
  A workflow follows application-defined control paths; an agent delegates some next-action decisions to a model.
- **[[AI Agent Learning/05 - Agent Systems/Multi-Agent Systems|Multi-Agent Systems]]**（多代理系統）
  Systems with multiple agent roles or instances that coordinate toward an objective.
- **[[AI Agent Learning/05 - Agent Systems/Agent Orchestration|Agent Orchestration]]**（代理編排）
  The control layer that coordinates model calls, tools, agents, state transitions, retries, and stopping rules.
- **[[AI Agent Learning/05 - Agent Systems/Human-in-the-loop|Human-in-the-loop]]**（人工介入）
  A design where a person supplies information, reviews output, or approves a specified action at a meaningful point.
- **[[AI Agent Learning/05 - Agent Systems/Guardrails|Guardrails]]**（行為與安全限制）
  Checks and restrictions that constrain model inputs, outputs, and available actions.
- **[[AI Agent Learning/05 - Agent Systems/SQL and Data Agent|SQL and Data Agent]]**（資料庫／資料代理）
  An agent that inspects schemas and uses queries or analysis tools to answer questions about structured data.
- **[[AI Agent Learning/05 - Agent Systems/Code Agent|Code Agent]]**（程式代理）
  An agent that works with code through file inspection, editing, execution, and verification.
- **[[AI Agent Learning/05 - Agent Systems/Browser and Computer Agent|Browser and Computer Agent]]**（瀏覽器／電腦操作代理）
  An agent that observes and interacts with user interfaces using browser elements, accessibility information, or screenshots and input actions.
