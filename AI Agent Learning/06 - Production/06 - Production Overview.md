## Key Concepts

### Study Sequence

- **[[AI Agent Learning/06 - Production/Agent Evaluation|Agent Evaluation]]**（代理評估）
  Systematic measurement of whether an agent behaves correctly and completes intended tasks under defined conditions.
- **[[AI Agent Learning/06 - Production/Accuracy|Accuracy]]**（準確率）
  The proportion of evaluated predictions or answers that match a defined correctness criterion.
- **[[AI Agent Learning/06 - Production/Retrieval Recall|Retrieval Recall]]**（檢索召回率）
  The fraction of relevant items retrieved from all relevant items for a query, often measured at a cutoff k.
- **[[AI Agent Learning/06 - Production/Precision|Precision]]**（精確率）
  For retrieval, the fraction of returned items that are relevant to the question.
- **[[AI Agent Learning/06 - Production/Groundedness|Groundedness]]**（證據支持程度）
  The degree to which generated claims are supported by the evidence supplied or cited.
- **[[AI Agent Learning/06 - Production/Task Success|Task Success]]**（任務成功率）
  Whether a run achieves the user’s specified outcome under its constraints; success rate aggregates this across runs.
- **[[AI Agent Learning/06 - Production/Observability and Tracing|Observability and Tracing]]**（可觀測性／追蹤）
  Observability uses telemetry to understand system behavior; tracing records related steps within a run.
- **[[AI Agent Learning/06 - Production/Latency|Latency]]**（延遲）
  Elapsed time between a request and an observable response or completed task.
- **[[AI Agent Learning/06 - Production/Cost|Cost]]**（成本）
  Resources spent on a run, such as model tokens, tool usage, storage, and compute.
- **[[AI Agent Learning/06 - Production/Security|Security]]**（安全性）
  Protecting data and operations through access controls, isolation, validation, and reliable trust boundaries.
