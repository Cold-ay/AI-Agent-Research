## Key Concepts

### Study Sequence

- **[[AI Agent Learning/01 - Fundamentals/AI Agent|AI Agent]]**（人工智能代理）
  A system that uses a model to choose actions toward a goal, observe results, and adjust its next step.
- **[[AI Agent Learning/01 - Fundamentals/LLM|LLM]]**（大型語言模型）
  A large language model learns statistical patterns from training data and generates token sequences conditioned on its current input.
- **[[AI Agent Learning/01 - Fundamentals/Tokens|Tokens]]**（詞元）
  Tokens are the units a model encodes and generates: words, word fragments, punctuation, or other representations.
- **[[AI Agent Learning/01 - Fundamentals/Context Window|Context Window]]**（上下文視窗）
  The bounded amount of information a model can consider during a request, measured in tokens.
- **[[AI Agent Learning/01 - Fundamentals/Prompting|Prompting]]**（提示設計）
  Designing instructions, examples, context, and output requirements to guide a model.
- **[[AI Agent Learning/01 - Fundamentals/Structured Output|Structured Output]]**（結構化輸出）
  Output constrained to a machine-readable structure, often a JSON schema.
